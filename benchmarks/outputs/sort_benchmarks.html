Sorting benchmarks

Radix sort, bucket sort, bitonic sort and name sort from SpeedUp, against the standard library. Time per element: lower is better, both axes logarithmic. Every result was checked against std::sort before it was timed. Run-to-run noise on this machine is about 10–15 %.

Name sort on real name lists

Compiler: gcc; ns per name at the full list, median of 7 runs. Every list was also sorted in caseless order and checked against qsort (all correct). On the Census surnames name sort is 1.6-3.2x faster than std::sort but 1-39 % slower than plain MSD radix sort: the 162,253 short, unique surnames are just above the 131,072-name planning threshold, which was tuned on longer 'Surname Firstname' strings, and MSD radix sort separates short names in few passes. On the 1M multilingual list the plan pays again.
